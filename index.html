Teamtrail guides

Guides your coding agents can take on. Each is a plain markdown file. The lint looks for common problems; it isn't a review. A guide is Verified when a maintainer reviewed this exact file (its hash is in verified.json). Read a guide before you approve it: installing one pins its hash, and any check command it proposes runs only after you approve that too.
